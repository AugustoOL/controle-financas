# Roteiro dos Vídeos

## Vídeo 1 — Solução em funcionamento (mínimo 5 min, narrado)
| Tempo | O que mostrar e falar |
|---|---|
| 0:00–0:30 | Apresentação: seu nome, o problema (falta de controle do dinheiro) e a solução |
| 0:30–1:30 | Repositório no GitHub: pastas `backend`, `frontend`, `database` e `docs`; explicar o MVC (model, view, controller) |
| 1:30–2:30 | Banco de dados: DER, dicionário de dados e `database/schema.sql` |
| 2:30–4:00 | Demonstração: criar categoria, registrar receita e despesa, editar, excluir, filtrar |
| 4:00–4:40 | Tratamento de erros: valor negativo, descrição vazia, categoria duplicada |
| 4:40–5:30 | Rodar `python -m pytest -v` (dentro de `backend`) mostrando os 30 testes passando |
| 5:30–6:00 | Conclusão e link da solução hospedada |

## Vídeo 2 — Solução atualizada (até 5 min)
| Tempo | O que mostrar e falar |
|---|---|
| 0:00–0:30 | Como foram os testes com os 5 colegas |
| 0:30–3:30 | Para cada erro: mostrar o print do problema → a correção no código → o resultado funcionando |
| 3:30–4:30 | Melhorias sugeridas que foram incluídas (e as que ficaram de fora, com o motivo) |
| 4:30–5:00 | Conclusão e aprendizados |
